# Root2Rise - AI-Powered Learning Platform Landing Page

A modern, responsive landing page for an AI-powered learning platform focused on Healthcare, Agriculture, and Urban/Smart City domains.

## Tech Stack

- **React.js** - Functional components
- **Tailwind CSS** - Styling and responsive design
- **React Icons** - Icon library
- **Framer Motion** - Subtle animations and transitions

## Features

- ✅ Sticky header with search and navigation
- ✅ Hero section with carousel (3 slides)
- ✅ Trusted By section with 6 partner logos
- ✅ Benefits/Invest section with 3 cards
- ✅ Domains section (Healthcare, Agriculture, Smart City)
- ✅ Student Reviews with rating distribution
- ✅ FAQ accordion section
- ✅ Responsive footer

## Getting Started

### Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm start
```

The app will open at [http://localhost:3000](http://localhost:3000)

### Building for Production

```bash
npm run build
```
